Discord 元数据检测器 · 设置

检测 Discord 网页版图片附件里的 AI 绘图元数据（A1111 / ComfyUI / NovelAI / InvokeAI / Fooocus / SwarmUI 等），分类结果为 NovelAI / 本地 AI 工具 / 无提示词三类。

扫描

NovelAI 会把提示词另外写进 PNG 的 alpha 通道最低位；有些图连 Comment 文字块都没有，提示词只剩这份隐写数据。省流量流程：先只读文件前 ~15%（前 152 行就够判断有没有隐写标记）→ 不中就停；没有 alpha 通道的 PNG 连这一段都不用读；只有确认有隐写才下载整份去解出提示词。同一个开关在扩展弹窗顶部也能改。
